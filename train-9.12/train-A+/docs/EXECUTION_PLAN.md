# 无人机绝缘子缺陷检测可执行方案

## 目标

实现 Geo-ROI-YOLO：面向无人机电力线路巡检的两阶段轻量级绝缘子缺陷检测流程。

核心链路：

```text
CPLID VOC XML -> YOLO 数据集 -> 全图 baseline
                  -> 第一阶段绝缘子检测
                  -> ROI 裁剪放大
                  -> 第二阶段缺陷检测
                  -> 缺陷合成增强
                  -> 几何先验后处理
                  -> 可视化结果 / ONNX 导出 / 消融表
```

## 论文贡献落点

1. 两阶段 ROI 检测：先定位绝缘子串，再在放大后的 ROI 中检测小缺陷。
2. 缺陷合成增强：针对样本少的问题，生成缺片、暗斑、裂纹类缺陷 ROI。
3. 几何先验后处理：利用绝缘子串周期结构，融合 YOLO 置信度与结构异常分数。
4. 低算力可复现：默认使用 YOLO11n 和 CPU/MPS，适合笔记本完成。

## 推荐实验顺序

1. `YOLO11n-full`：整图训练，作为 baseline。
2. `Stage1 + ROI-YOLO`：训练绝缘子定位器，生成 ROI，训练缺陷检测器。
3. `ROI-YOLO + synthetic defects`：加入合成增强并重新训练第二阶段。
4. `ROI-YOLO + geo prior`：推理时启用几何融合后处理。
5. `ROI-YOLO-P2`：在前面结果稳定后，再加入 P2 小目标头作为消融项。

## 投稿叙事

不要把创新点写成“又改一个 YOLO 模块”。主线应写成：

```text
无人机图像中缺陷占比极小 -> 全图检测易漏检 -> ROI 放大提升有效像素
缺陷样本少 -> 物理一致性合成增强
复杂背景误检 -> 周期结构几何先验抑制误检
```
