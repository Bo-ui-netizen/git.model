# Geo-ROI-YOLO 新手运行说明

## 这个项目在做什么

它的目标是从无人机拍摄的电力线路图片中找出绝缘子缺陷。

流程分为两步：

1. 第一阶段在整张无人机图中寻找绝缘子。
2. 把每个绝缘子区域裁剪、放大，再由第二阶段寻找很小的缺陷。

这样做的原因是：缺陷在整张图中太小，直接检测容易漏掉；先把绝缘子放大，缺陷会更明显。

在资源管理器进入 `D:\GeoROI-YOLO`，点击地址栏，输入 `powershell` 后按回车。

以后每次先执行：

```powershell
.\.venv\Scripts\Activate.ps1
```

出现 `(.venv)` 即表示项目 Python 环境已启用。

## 完整训练顺序

先训练第一阶段（找绝缘子）：

```powershell
python train_stage1.py --data data/cplid_insulator_windows.yaml --model yolo11n.pt --imgsz 640 --epochs 80 --batch 4 --device cpu --name stage1_insulator
```

再训练第二阶段（找缺陷）：

```powershell
python train_stage2.py --data data/cplid_defect_roi_windows.yaml --model yolo11n.pt --imgsz 768 --epochs 120 --batch 2 --device cpu --name stage2_defect_roi
```

说明：当前环境的 PyTorch 是 CPU 版，所以命令中必须写 `--device cpu`。电脑有 RTX 4060，但 CUDA 版 PyTorch 尚未安装完成；装好后把 `cpu` 改为 `0`，训练会快很多。

## 用训练后的模型预测

把下面的图片路径换成你想检测的 `.jpg` 图片：

```powershell
python infer_pipeline.py --image "你的图片.jpg" --stage1 "runs\detect\stage1_insulator\weights\best.pt" --stage2 "runs\detect\stage2_defect_roi\weights\best.pt" --out outputs\infer --device cpu
```

输出图片会在 `outputs\infer` 中：橙色框表示绝缘子区域，红色框表示缺陷。

## 指标怎么看

- Precision（精确率）：模型说“有缺陷”的结果中，有多少是真的。
- Recall（召回率）：真实缺陷中，模型找到了多少。
- mAP50：综合评价检测效果，越接近 1 越好。

训练 1 轮仅用于确认程序没有问题；论文要使用完整训练结果，再记录完整训练结束时的 Precision、Recall 和 mAP50。
